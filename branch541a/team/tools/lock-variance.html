01 / VOCABULARY

Learn the language first.

Every lock problem starts with a team member not being 100% sure what a term means. Tap any term to expand. Nothing else in this guide matters if your team is guessing at these.

Lock Variance +
When the loan data in the system no longer matches what was locked with Secondary. FT360 shows Lock Variance: YES in the Borrower Ribbon until it is resolved.
Lock Validation +
The process of clearing a lock variance. Either the lock gets updated to match the new data, or the data is confirmed to still fit the locked pricing. Submitted through Optimal Blue via FT360. See Section 03.
Profile Change +
The Optimal Blue term for a lock validation / change request when loan attributes have changed. Triggered from the Lock Verification form or Services tab in FT360.
Relock +
A new lock issued after the original lock expired or was cancelled. Comes with a worse-case pricing policy — borrower gets the worse of the original lock or current market. Not a free reset.
Lock Extension +
Pushing the lock expiration date out before it expires. Cheaper than a relock. Priced in 5-day increments typically. See Section 04.
Float Down +
A one-time option to lower a locked rate if the market drops a qualifying amount after lock. Rules vary by program and are not automatic — must be requested in writing.
Worst-Case Pricing +
Applied when a lock expires and is relocked, or when a loan falls out and returns. Borrower is charged the worse of the original pricing or current market pricing on the day of relock.
LLPA +
Loan-Level Price Adjustment. Pricing adjustments driven by FICO, LTV, occupancy, loan purpose, property type, DTI, and other risk factors. Changing any of these triggers a lock variance.
Intraday Reprice +
A mid-day rate sheet change. Happens when the market moves enough during the day that PRMG must update pricing before the next day's sheet. If you have a rate quoted but not locked, it can disappear. See Section 08.
Par / Above Par / Below Par +
Pricing of 100.000 is par (no cost, no credit). Above 100 = lender credit back to borrower. Below 100 = borrower pays discount points. Example: 99.799 = $402 cost on a $200K loan / 100.125 = $250 credit.
BPS (Basis Points) +
1 basis point = 0.01% = $1 per $10,000 of loan amount. Extension and float-down fees are quoted in bps or price hits. 25 bps on a $300K loan = $750.
Manual Lock +
A lock that was entered by Secondary directly, not through Optimal Blue's automated system. Validations on manual locks must be submitted by email to Secondary — the automated Change Request button does not work.
02 / WHAT IS A LOCK VARIANCE

The three-column comparison that drives everything.

FT360 compares three sets of loan data on every file: what was originally locked, what is in the loan file right now, and what the underwriter approved. Any mismatch on a pricing-sensitive field triggers LOCK VARIANCE: YES and the loan cannot close until it is cleared.

The three columns FT360 compares

ColumnWhat it showsWho updates it
Borrower — Current Loan DataLive data from the 1003, URLA, and 2015 Itemization as of right now.LO / Processor as the file evolves
Borrower — Locked Loan DataThe exact data frozen at time of lock. This is what Secondary priced against.Locked once — never changes unless relocked
Borrower — UW Approved Loan DataThe data the underwriter based their approval on.Underwriter on each decision

Fields that commonly trigger a lock variance

ChangeTriggers variance?Why
Loan amount increases or decreasesYESChanges LTV tier — new LLPA
LTV / CLTV moves into a new tierYESLLPA table jump
DTI crosses a thresholdYESDTI-based LLPA on Conv / FHA high-balance
FICO drops into a worse tierYESFICO-based LLPA
Loan program changes (FHA → Conv, 30yr → 15yr)YESDifferent product entirely — requires relock
Property type changes (SFR → condo / 2-4 unit)YESProperty-type LLPA
Occupancy changes (Primary → Investment)YESMajor LLPA shift
Purpose changes (Purchase → Cash-out refi)YESCash-out LLPAs stack
Escrow waiver added or removedYESWaiver LLPA on Conv
Borrower name spelling correctionsNOCosmetic — not priced
Property address correction, same propertyNONot pricing-relevant

▲ COMMON MISTAKE

Loan amount goes up by $2,000 because taxes and insurance were re-escrowed. Team thinks it's too small to matter — it is not. If the new amount crosses an LTV tier, the lock must be validated or funding is blocked.

03 / LOCK VALIDATION PROCESS

The Optimal Blue Change Request — 8 steps.

This is the process introduced in FT360 v19.14. Before this, every lock validation required emailing Secondary. Now most validations go straight into Optimal Blue and update automatically in 2–3 minutes.

◆ WHEN TO USE THIS

Use the Change Request button on the Lock Verification form whenever LOCK VARIANCE: YES appears on a file. For manual locks, the Change Request button will be replaced by a MANUAL LOCK VALIDATION button that auto-opens an email to Secondary — see Section 11.

1
Open the loan → Lock Verification (PRMG) form
In FT360, open the loan. Find the Lock Verification (PRMG) form. Confirm Lock Variance: YES at top right. Look at the three columns to identify what changed.
2
Click "Change Request" on the Lock Verification form
The Change Request button is in the "Enhancements and Training Material" section. This opens Optimal Blue directly. (Alternative: Services tab → Search Product and Pricing → Optimal Blue Enhanced → Submit.)
3
Log into Optimal Blue (first time only)
Enter your Optimal Blue login and password. Check "Save Login Information" so you never have to enter it again.
4
Click the Change Request icon (4th icon from the left)
In the Optimal Blue ribbon. Hover text: "Change Request". Loan status should show as Locked.
5
Select "Profile Change" → First Lien → Profile Change
Select Profile Change. Under "Select Lien" choose First Lien. Then click the Profile Change button.
6
Submit → select the product in BOLD → select the rate
Click Submit. Always select the product shown in BOLD — that is your originally-locked product. The current locked rate will be highlighted in orange. Click the lock icon next to the orange row.
7
Review the change summary → Apply Change → Submit
A before/after comparison table appears. Review carefully. Click Apply Change, then Submit.
8
Click OK → Logout → EXIT the loan
Click OK. Click Logout. Then exit the loan entirely. Optimal Blue cannot update the lock while the loan is open. Come back in 2–3 minutes — Lock Variance will read NO.
▲ MOST COMMON FAILURE

Team submits the Change Request and stays in the loan. Two hours later they come back confused because Lock Variance still says YES. Exit the loan after clicking OK. This single step breaks more lock validations than anything else.

04 / LOCK EXTENSIONS

Extend before you expire — every time.

An extension costs a fraction of a relock. If the lock will expire before the funded date, extend it the day you know. Not the day it expires.

Extend the moment you know you will miss the lock expiration. The longer you wait, the more expensive an extension gets. Secondary's extension schedule gets worse each day past day 5.

▲ PROGRAM SWAP = RELOCK

A program change (FHA to Conv, or 30-year to 15-year fixed) is not a profile change. It is a new product. Email Secondary — do not try to do it through the Change Request button.

06 / FLOAT DOWN

Lower the locked rate when the market drops.

RuleDetail
When it triggersMarket must have dropped at least 0.250 in rate (25 bps) since lock date.
One-time onlyOne float down per loan. Use it when confident the market has bottomed.
Requires Secondary approvalEmail lockrequests@prmg.net with the loan number, borrower name, and reason.
CostA fee — typically the difference is split. Borrower gets a portion of the improvement, not the full amount.
TimingMust have at least 7 days left on the lock and cannot be within 48 hours of closing.
EligibilitySome programs (certain Non-QM, Chenoa, investor-specific) are not eligible. Confirm before promising.
◆ WHEN TO OFFER A FLOAT DOWN

Borrower calls nervous because a friend got quoted a lower rate. Before promising anything, check current pricing and call Secondary. Confirm there is room. Then offer it.

07 / LOCK EXPIRATION + RELOCK

What happens when a lock expires — and how to recover.

Days past expirationStatusAction
T-5 days (still active)OKExtend now if closing will slip.
T-1 dayLAST CHANCEExtend today. Do not wait for morning.
Day 0 (expired)EXPIREDLock is dead. Must relock at worse-case pricing.
Day 1–29 past expirationRELOCK ELIGIBLEWorse-case pricing — original lock or current market, whichever is worse.
Day 30+ past expirationNEW LOCKTreated as a brand-new lock at current market.
▲ PREVENTABLE

Every expired lock was avoidable. Build a 5-day-before-expiration alert in your pipeline. Review lock expiration dates every Monday morning. No lock should ever expire on an active file.

08 / INTRADAY REPRICING

The mid-day rate sheet that kills deals.

SituationDefensive action
Major economic data scheduled at 8:30 AM ETLock before 7 AM PT or wait until after 9:30 AM PT dust settles.
Fed day (FOMC statement at 11 AM PT)Lock the day before or float through lunch. Never lock at 10:55 AM PT on a Fed day.
Rate sheet just dropped intradayDo not send LEs quoting the old rate. Wait for new sheet.
Lock submitted before reprice but not confirmedIf you have a timestamp before the reprice time, you are usually protected. Confirm with Secondary in writing.
◆ LANGUAGE TO USE WITH BORROWERS

"I want to be clear about how this works — rates are tied to the bond market and they move throughout the day. I can quote you where they are right now, but the rate is not yours until we lock it in writing. If you tell me to lock, I can do it within the hour."

11 / SUBMITTING TO SECONDARY

When Change Request won't work, email Secondary.

When to email Secondary instead of using Change Request

  • The lock is a manual lock
  • You need a price exception
  • Full program change (FHA ↔ Conv, 30yr ↔ 15yr)
  • Lock has been expired more than 30 days
  • Something broke in Optimal Blue and Change Request won't go through
  • Jumbo or Non-QM loans where the investor does not live in Polly
◆ EMAIL TEMPLATE — TO: lockrequests@prmg.net

Subject: [Request Type] — Loan # [XXXXXXX] — [Borrower Last Name] Borrower Name: Loan Number: Property Address: Current Locked Rate / Price / Expiration: Requested Change: Reason: Closing date: Jose Del Valle-Figueroa · Branch 541-A · PRMG · NMLS #2686066 · JDelValle@prmg.net

◆ EXPECTED RESPONSE TIMES

Lock validations via Change Request: 2–3 minutes (automated).
Email to lockrequests@prmg.net: same business day, typically within 2 hours during East Coast trading hours.
Price exceptions over 0.500: expect 4–24 hour turnaround.

12 / WHO HANDLES WHAT

Role clarity. Every lock task has one owner.

  • Initial lock decision — when to lock, what rate, what term.
  • Communicating rate and lock terms to the borrower in writing.
  • Running Polly pricing and submitting the initial lock request.
  • Deciding whether to float down, extend, or accept a worse-case relock.
  • Approving any price exception requests before they are sent to Secondary.
  • Owning the rate conversation with the borrower — processor does not quote rates.
  • Monitoring MBS Highway alerts and reacting to intraday repricing.
  • Running the Change Request on routine profile changes after LO confirms.
  • Flagging lock variances in the pipeline as soon as they appear.
  • Monitoring lock expiration dates weekly — flagging any file within 10 days of expiration to the LO.
  • Verifying the three-column comparison on the Lock Verification form.
  • Uploading lock confirmations to the file.
  • Responsible for exiting the loan after any Change Request submission.
  • Processing all lock requests submitted through Polly / Optimal Blue.
  • Reviewing and approving / declining price exception requests.
  • Handling manual locks outside the Optimal Blue workflow.
  • Owning the lockrequests@prmg.net inbox — Amy Morse is the primary contact.
  • Issuing guidance when market conditions trigger intraday repricing.
  • Approving price exceptions over 0.500 before submission to Secondary.
  • Approving manual overrides to 2015 Itemization 802 lines.
  • Final call on whether to absorb branch-level lock extension costs to save a deal.
  • Weekly pipeline review — every file with Lock Variance YES and every file within 10 days of expiration.
13 / DECISION TREE

"My lock situation is ___." Click your answer.

What is happening with the lock?
Lock Variance Clearance: Open loan → Lock Verification (PRMG) form → check 3-column comparison → click Change Request → log into OB → 4th icon → Profile Change → First Lien → select bold product → select orange highlighted rate → Apply Change → Submit → OK → Logout → EXIT THE LOAN. Variance will clear in 2–3 minutes. See Section 03.
Extension Needed: Open loan → Change Request → Lock Extension → First Lien → choose days (5-day increments, add 5-day buffer) → Select Extension → Request → Submit → Logout → Exit. See Section 04 calculator.
Relock Required: Change Request → Relock → First Lien → accept worse-case pricing. Talk to the borrower before submitting. Document in file notes. See Section 07.
Float Down: Verify market has moved 0.250+ since lock. Confirm program is float-down-eligible. Email lockrequests@prmg.net: "Float Down Request — Loan # X — Borrower". Wait for written confirmation before telling the borrower. See Section 06.
Full Relock: NOT a Profile Change. Email lockrequests@prmg.net: "Program Change Lock — Loan # X — Borrower". Old lock cancels, new lock at current market pricing. See Section 05.
Triage Every Unlocked File: Check MBS Highway alert. Call every borrower with a quoted-but-not-locked rate within 1 hour. Be honest about the rate movement. Document every conversation. See Section 08.
Missing Confirmation: Email lockrequests@prmg.net with loan number and timestamp. Do not resubmit — that can create duplicate lock requests.
Chenoa Second Lien: Email locks@chenoafund.org — "Chenoa Lock Extension Request — [Borrower] — PRMG Loan #". Email PRMG Secondary the same day for the first lien extension. See Section 10.
